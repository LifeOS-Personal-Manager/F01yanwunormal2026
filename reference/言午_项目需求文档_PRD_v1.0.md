## 1. 产品定义

言午是面向学龄儿童与青少年的家庭成长协作工作台。父母及授权照护者共同记录孩子的生活、学习、兴趣和沟通情况，围绕事实确定支持行动、分工、确认方案并定期回顾。

首个场景按6岁、一年级家庭设计，支持从家长陪伴逐步过渡到孩子自主成长。首版成年人独立登录，一个家庭管理一个孩子；数据结构保留多孩子扩展能力。孩子的表达由成年人如实转录并注明来源，不生成孩子账号。

核心闭环：查看状态 → 记录变化 → 共同跟进 → 执行行动 → 回顾与调整。

### 1.1 要解决的问题

- 家庭信息分散，照护者不知道最新安排、已采取行动和待确认事项。
- 观察与评价混杂，难以还原事实和孩子自己的想法。
- 关注事项缺负责人、下一步和回顾时间，反复讨论却没有闭环。
- 只关注作业结果，缺少兴趣、生活、沟通与家长自身改进的记录。

### 1.2 产品边界

首版不做实时定位、设备监控、聊天采集、儿童排名、人格标签、情绪评分或诊断。家庭沟通改进属于独立责任，不以孩子先配合或道歉为条件。长期方向可以调整，不要求将孩子的发展压缩为统一分数。

本文不设医学阈值或治疗建议。界面仅提供由用户主动选择的“寻求外部支持”标记与联系行动记录。

## 2. 用户、角色和使用环境

| 角色 | 主要职责 | 权限原则 |
|---|---|---|
| 家庭所有者 | 创建家庭、邀请成员、管理成员、导出和删除家庭 | 管理身份不自动获得所有受限正文 |
| 监护人 | 记录、作业协作、制定方案、执行与回顾 | 可操作授权可见内容 |
| 照护者 | 如祖辈，处理明确授权的陪伴与任务 | 默认只访问具体授权内容 |
| 孩子（参与者） | 表达感受、共同选择目标和行动 | 首版无登录账号，由家长转录 |

首版支持桌面浏览器和手机浏览器；可安装PWA作为交付目标，离线仅展示断网说明，不承诺离线业务编辑。家庭时区默认Asia/Shanghai，可调整；每个人使用独立账号，共享后端数据。

## 3. 版本范围与优先级

P0必须在首版完成；P1安排下一阶段；P2为探索项。

| 编号 | 模块 | 首版P0 | 后续范围 |

| FR-02 | 孩子档案 | 单孩子资料、兴趣优势、孩子表达、当前支持方式 | 多孩子、孩子端P1 |
| FR-03 | 首页 | 今日行动、待确认、近期支持、变化与协作动态 | 个性化布局P1 |
| FR-04 | 成长记录 | 新增、编辑、时间线、分类筛选、评论、转跟进 | 日历视图、附件P1 |
| FR-05 | 学习安排 | 新增作业、支持方式、状态、截止、反馈 | 课程表、考试、OCR P1/P2 |
| FR-06 | 共同跟进 | 事实、孩子表达、负责人、行动、方案版本、确认、回顾 | 家庭会议模板P1 |
| FR-07 | 成长方向 | 长期/阶段目标、周行动、家长支持、文字回顾 | 学期报告P1 |

| FR-09 | 趋势 | 手工睡眠/运动/阅读数据、有效样本说明 | 更多统计P1；情绪量化不纳入 |

## 4. 信息架构

六个主导航：首页、孩子档案、成长记录、学习安排、共同跟进、成长方向。家庭设置位于头像菜单。新增记录是桌面侧栏、手机全屏表单，不增加主导航。共同跟进包含列表与详情。

首页信息顺序：今日重点 → 待确认 → 近期需要支持 → 近期变化 → 家庭动态。首屏优先行动，图表置后。

## 5. 功能需求

### 5.1 FR-01：账号与家庭

所有者创建家庭并填写时区；首次添加孩子可仅填写昵称与年级，出生日期选填。生成限时单次邀请链接，由用户自行分享，系统不自动发送消息。邀请绑定预期账号标识，接受时核验登录身份；有效期默认7天，可撤销。接受成功后立即生效。

最后一位所有者不能退出，必须转移所有权或删除家庭。移除成员后立即禁止读取与修改，历史记录保留署名快照；其未完成任务转入待重新分配列表。邀请新成员不自动分享历史受限资料。

### 5.2 FR-02：孩子档案

必填昵称、学习阶段；可填出生日期、年级、兴趣、优势与阶段性支持方式。出生日期未填不猜年龄。学校、班级、健康备注、紧急联系人均选填，健康信息独立限制访问。

“兴趣优势”记录事实与时间，不使用固定能力等级。孩子表达包含原话、转录人、表达时间及表达状态：已表达、尚未询问、暂不想说。后两者不能生成推测文本。

### 5.3 FR-03：首页

- 今日重点汇总今日截止与逾期未完成行动、作业；显示来源、主负责人、状态和下一步。
- 待确认仅显示当前用户需要确认的最新方案版本；已读与确认分开。
- 近期支持显示待回顾跟进，默认先逾期再按日期排序；紧急程度由人明确选择。
- 当前状态仅引用有时间和来源的记录，无记录显示“今天尚未记录”。不自动推断“平稳”。
- 动态只展示可见对象的协作动作，支持“查看全部”；不暴露不可见内容数量或标题。
- 日期筛选、统计与排序按家庭时区执行。

### 5.4 FR-04：成长记录

快速表单：发生了什么（必填）、分类（必填，默认其他观察）、孩子怎么说（选填）、发生时间（默认现在）、谁可以看到（展示成员名单）。扩展字段为家长观察、采取行动、后续计划。

分类：学习、情绪、生活习惯、身体健康、兴趣活动、人际关系、亲子沟通、重要事件、阶段进步、其他观察。

保存后可转为跟进，复用事实与孩子表达并保留来源链接；负责人和下次了解日期必填。创建过程原子提交，失败不产生孤立对象；重复点击不创建多个跟进。受限记录转跟进时默认沿用权限，扩大可见范围需明确选择并提示分享内容。

作者编辑事实；其他成员通过评论补充，不静默改写原话。转录孩子表达必须注明是转录，不能显示为孩子本人提交。

### 5.5 FR-05：学习安排

| 字段 | 规则 |
|---|---|
| 科目、内容、截止时间 | 必填；仅选日期时解释为家庭当地当日23:59 |
| 布置日期、来源 | 日期默认今天，来源选填 |
| 预计/实际用时 | 选填非负分钟，不用于排名 |
| 支持方式 | 自己完成、需要提示、需要陪伴、需要向老师求助 |
| 支持负责人 | 需要成人介入时必填 |
| 是否检查 | 默认否；是则指定检查人 |
| 孩子反馈、家长反馈 | 可为空，分别显示来源 |

状态为未开始、进行中、待检查、已完成。无需检查可以直接完成；需检查必须经待检查，由指定检查人确认完成。待检查可以退回进行中，必填修改说明。已完成可重开，记录原因。

逾期是独立派生标记：当前时间超过截止且未完成、未归档。修改截止时间保留变更记录。删除/归档作业不计入有效统计。

### 5.6 FR-06：共同跟进

跟进覆盖学习困难、生活习惯、情绪观察、同伴关系、亲子沟通、电子设备约定、健康、学校沟通、安全、兴趣探索和其他事项。

字段：标题、事实、发现时间、孩子表达、家长判断（独立字段）、主要负责人、协作人、目标、下一步、回顾时间、紧急/影响程度（人工选填）、外部支持标记。

状态：待了解 → 行动中 → 待回顾 → 已结束。允许待回顾调整后回到行动中，已结束可重开；结束必须写回顾结论，不等于永久解决。外部支持为独立字段，不阻断状态流转。

方案包含孩子行动、家长行动、支持方式、需确认成员。默认需所有参与方案的监护人确认；至少一名有效监护人，单家长家庭可自行确认并标明“单人确认”。指定对象须有方案访问权限。

确认动作：同意方案、提出修改；已读仅说明查看过。所有必需确认人同意当前版本才进入执行。修改方案内容、确认人或行动分工会产生新版本并重新确认，旧确认保留历史。紧急事项可记录先行行动，但不得显示“已达成共识”。

### 5.7 FR-07/11：目标与行动

目标层级为长期方向 → 阶段目标 → 具体行动。长期方向不显示百分比；阶段目标记录原因、孩子是否认可（认可/待讨论/不同意）、支持方式、证据、回顾日期。

每项行动有标题、一个主负责人、可选协作人、截止时间和状态。孩子行动的执行主体可为孩子，但首版记录责任人为成人；不得伪装为孩子登录操作。家长行动独立完成与回顾。

行动状态为待开始、进行中、已完成、已取消。取消需原因，不算完成。数量目标仅用于明确计数的行动，如完成2次/计划3次；不生成综合成长分。

### 5.8 FR-08：评论、已读与同步

评论继承所属对象权限；显示作者和时间，可由作者编辑/删除并标记变更。已读针对对象版本，最新方案变更后重新提示。站内通知去重，只给有权用户显示必要摘要。

保存中、已保存、同步中、同步失败必须真实区分。另一位家长在正常联网时应自动看到更新；冲突不得以最后写入覆盖。首版站外推送不交付。

### 5.9 FR-09：指标与数据可信度

| 指标 | 首版口径 |
|---|---|
| 睡眠 | 每个本地日期一条确认值；跨午夜归入起床日；平均值为总分钟/有效天数 |
| 运动 | 每日分钟及次数；未记录与明确0区分 |
| 阅读 | 每日分钟；记录大于0的日期计阅读天数 |
| 作业完成率 | 所选期间截止的有效作业中，目前完成数/有效总数；说明是当前快照 |
| 沟通记录 | 按发生时间计数，不解释为亲子关系质量 |

所有图表标注统计周期、单位、有效样本量、数据来源；缺失不填零。周比较固定为最近完整7天与此前7天，各期有效记录至少4天才显示变化，并显示样本数；低于阈值显示“记录不足”。该阈值是产品展示规则，不是健康判断标准。

### 5.10 FR-10：权限、导出与删除

每项业务内容绑定家庭、孩子与可见成员。普通内容默认当前监护人，照护者需要指定；敏感内容默认创建人，可主动授权。权限不得仅依赖前端隐藏。

个人导出包含本人有权访问的数据；家庭所有者导出共享数据及其获授权受限数据，明确列出范围，不能绕过私密权限。输出JSON（结构化完整关系）和CSV（可平铺记录），首版不承诺一键恢复导入。

删除采用30天可恢复期，界面明确截止时间；到期从业务存储清除，备份最长再保留30天。所有者可删除整个家庭，需二次输入家庭名；删除范围覆盖所有家庭资料，即使其不能阅读受限正文。审计仅保留最小操作元数据，不保存已删除正文。

## 6. 非功能需求与验收目标

以下为计划验收值，不是已验证结果。

| 项目 | 验收目标 |
|---|---|
| 易用性 | 首次使用者30秒内找到今日下一步；常规记录60秒内完成 |
| 兼容 | 360px手机到1440px桌面无横向溢出；键盘可完成主要操作 |
| 可访问性 | 正文对比度至少4.5:1，控件有标签，状态同时有文字 |
| 性能 | 约定测试网络下首页主要内容3秒内显示，普通接口P95小于800ms |
| 同步 | 正常网络下其他在线成员10秒内看到已提交更新；断线有提示 |
| 一致性 | 重复提交不重复建单；旧版本写入返回冲突；事务失败不半保存 |
| 权限 | 跨家庭、撤权后访问、统计/导出旁路访问均被拒绝 |
| 恢复 | 每日备份，设计RPO≤24小时、RTO≤4小时；上线前实际演练 |
| 隐私 | 不公开索引家庭页；日志不记录正文、健康内容、令牌 |

## 7. 核心验收场景

| 编号 | 操作 | 通过标准 |
|---|---|---|
| AC-01 | 爸爸记录事件，妈妈补充评论 | 原事实、原话与评论来源清晰，两端自动同步 |
| AC-02 | 记录转跟进并指定负责人 | 不重复录入，不产生重复跟进，权限保持一致 |
| AC-03 | 两位家长确认方案后修改 | 新版本重新待确认，旧同意不能继续算数 |
| AC-04 | 已读但未同意 | 不显示已达成共识 |
| AC-05 | 两人同时编辑同一条记录 | 后提交者收到冲突并可比较，不覆盖 |
| AC-06 | 设置需检查作业并提交 | 进入待检查，非检查人不能确认完成 |
| AC-07 | 作业截止后仍进行中 | 同时显示进行中和逾期 |
| AC-08 | 数据仅记录2天 | 显示样本2/7，不补零、不显示充分趋势结论 |
| AC-09 | 移除照护者后访问旧链接 | 详情、列表、统计与导出均不可访问 |
| AC-10 | 完成家长行动并回顾 | 可独立完成，不以孩子行动完成为条件 |
| AC-11 | 手机断网后提交 | 清楚报错并保留本页输入，不显示保存成功 |
| AC-12 | 删除和恢复、备份演练 | 在规则窗口内可恢复，权限不被扩大 |
| AC-13 | 跨时区午夜查看今日任务 | 按家庭日期稳定归组，不丢单不重复 |
| AC-14 | 导出受限数据 | 只包含有权对象及关联，不泄露隐私字段 |

## 8. 实施阶段与完成定义

1. 需求与原型：按两份文档画六个主页面和跟进详情；验证命名、表单与移动端信息顺序。
2. 基础底座：身份、家庭成员、孩子、权限、审计、数据库迁移与测试数据。
3. 核心闭环：记录 → 跟进 → 方案确认 → 行动 → 回顾；优先验证双账号协作。
4. 学习与方向：首页汇总、作业检查、目标行动、数值记录与趋势。
5. 交付：响应式、错误态、导出删除、备份恢复、部署文档与验收记录。

每阶段完成需有可运行功能、关联验收证据和已知问题清单。演示数据必须明确标记，正式账号默认空数据。首版上线阻断项：越权、数据丢失、确认版本错误、无法可靠保存、无法恢复备份。

## 9. 默认假设与后续决策

默认单家庭单孩子、成人账号、简体中文、家庭时区中国、站内同步、无附件与AI。正式开发前需结合真实运行环境确定域名、身份服务、部署位置、预算与备份存放方式；这些不阻碍需求与原型开展。不得将本次文档交付解释为已经完成网站或部署。

## 10. 需求变更规则

以FR编号记录变更原因、范围、数据影响、验收变化与版本。任何增加孩子端、附件、AI或外部分享的变更，都需同时更新权限模型与验收场景。实现细节以配套设计文档为准，若与本PRD冲突先修改需求基线，不由代码自行改变产品规则。
